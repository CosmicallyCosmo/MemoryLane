The model chooses. It never writes.

02 · The rule

A choice or a plan. Never free reign.

All four Gemini jobs go through one small REST client, server/src/gemini.js. Generative calls ask for JSON against a response schema, at temperature 0, with minimal thinking; recognition is a closed choice on the Decisions API. There only field the model could put a sentence for the wearer is a short guess at an everyday unknown object if confident and only if enabled in the web app.

// Every call: JSON against a schema
generationConfig: {
  responseMimeType: "application/json",
  responseSchema: schema,
  temperature: 0,
  maxOutputTokens,
  thinkingConfig: { thinkingLevel: "minimal" },
}
// models, tried in turn until the deadline
"gemini-3.5-flash-lite", "gemini-3.1-flash-lite"

Output is checked before use

A memory lane plan is cleaned against the memory's real files, so a photo that doesn't belong can never appear. A match below 0.6 counts as no match.

Told never to identify people

Faces aren't recognised at all. “Who is that?” is answered only from a framed photo, an object the family has labelled.

Minimal thinking, measured

Left to the default, a call with a few photos took about 12.5 s. With "minimal" the same calls answered in about 4 s, all correctly.

03 · Recognition

Is this that teapot, or just a teapot?

A keepsake is one physical object, not a category. Recognition goes through the Gemini Decisions API, which gives a probability for each memory and for “none of them”. A winner is then confirmed against that memory alone, feature by feature.

  1. LookOne JPEG, at most 768 px. The server gives a look 12 seconds.
  2. DecideEach memory is a numbered option with its name, features and reference photos, plus other.
  3. ThresholdThe winner needs at least 0.6, or it's no match.
  4. ConfirmSame object, or same kind? Each saved feature is checked: yes, no, or unseen.
  5. Offer or nameA match is offered. A miss is labelled and sent to the family as an idea.

Try a frame

Pick what the glasses see. Numbers are illustrative, the shape is the real response.

Without the confirmation, one look-alike matched at 0.997. A miss takes about 4 s, because the object is then named. Each memory also tests itself against two look-alikes of its own when it's added; all six in the recordings household passed.

These are test photos, not a real home. They show the wiring works, not accuracy in someone's living room.

Why the options are numbered

The model never sees option keys, so each keepsake's name, features and photos sit together under “option N”. With photos tied only by name, a different family's graduation photo matched at 0.88. Numbered this way: under 0.2.

A miss is useful too

Decisions writes no text, so on a miss the server asks Gemini vision for a plain label. “A yellow striped mug” goes to the family as an idea for a new memory, never the name of a keepsake.

04 · Answers

Asked once, answered from then on.

The phone hears the question. Gemini picks which of the family's recorded answers fits, or says “none”. A question with no answer goes to the family with a count of how often it's been asked.

// The wearer: "Where's Margaret?"
// Gemini sees the question and the recorded answers:
a_1  "Margaret's at the hairdresser's…"  (Sarah, voice)
a_2  "I'm coming on Saturday…"          (Sarah, voice)

// and can only return one of them, or none:
{ "answer_id": "a_1" }

Matched on the phone if needed

With no connection or no model reply, questions are matched by wording on the phone, against the answers it keeps.

Voices stay real

A recording plays as recorded. A typed answer is read by a neutral voice that says who wrote it.

When nothing fits

The wearer hears a fixed line saying so. A wrong answer is worse than none.

05 · Memory lanes

Gemini directs. Cloudinary cuts.

For a memory lane, Gemini listens to the relative's voice message and places each photo at the moment its subject is mentioned, with where the subject sits in the frame. That plan becomes one Cloudinary address. Ask for a change in words and watch the address rebuild.

From the demo household, Gemini's real note to the family: “I placed the graduation video right at the beginning to match Jake's opening greeting about the day he graduated.”

06 · Cloudinary

The film is an address.

The display takes a small silent MP4 from an https address: at most 400 pixels a side and 70,000 pixels in all. Families upload phone photos and videos of any size. Cloudinary is the whole path between the two. With CLOUDINARY_URL set, nothing for the glasses is rendered on our server or in a browser.

Sized for the lens

264 × 264, ac_none,vc_h264,q_auto. Inside the display's limits.

Slow fades, slow move in

fl_splice:transition_(name_fade;du_1.5) between photos; e_zoompan on the last one.

One video? Crop it smart

The plain crop goes out at once; c_fill,g_auto replaces it when Cloudinary has watched the clip.

Hellos find faces

A relative's hello video is cropped around the faces in it, g_auto:faces.

Tiles pick a frame

so_auto picks a still; c_fill,g_auto and f_auto,q_auto serve the browser's best format.

Made ahead, deleted for real

Lane clips get an eager display copy at upload. Removing a memory, hello or person removes their uploads too.

It runs in the background after every change: the family app says “Being made for the glasses now” and the page can be closed. The server asks for the address until Cloudinary has it ready (a 423 means it's still finding faces). The sound stays on our server, because the phone plays it through the glasses' speakers and keeps it for when there's no connection.

07 · On the glasses

Built on Meta's Device Access Toolkit.

The phone app is Kotlin on the Wearables Device Access Toolkit 1.0.1: camera, display, speech and motion. Tested on Meta's Mock Device Kit, with the phone's camera and mic standing in.

08 · Failing quietly

About one call in ten failed. That had to be fine.

On the free tier, roughly one Gemini call in ten got a 503 or no reply. So calls are short attempts inside a deadline, alternating two models, and every job has a fallback that needs no model at all.

// server/src/gemini.js · generate()
for (let attempt = 0; ; attempt++) {
  const remaining = deadline - Date.now();
  // No answer has ever come back in under 1.5 s.
  if (remaining < 1500) break;
  const model = MODELS[attempt % MODELS.length];
  // …fetch with AbortSignal.timeout(budget)
  // a 4xx other than 429 fails the same way
  // every time, so stop retrying
}

09 · Data & consent

Built to be trusted by a family.

Agreement first

The server refuses to look at any frame until the wearer, or whoever holds their legal authority, has agreed.

Frames aren't kept

A frame is checked and discarded; only the outcome is logged.

No face recognition

“Who is that?” comes only from a framed photo the family labelled.

Uploads need confirmation

That everyone pictured or recorded has agreed.

Opt-ins, off by default

Noting questions, listing unfamiliar objects, noting heart rate. Turning heart rate off deletes every session kept.

Meta SDK analytics off

And everything, including Cloudinary uploads, can be deleted.

The Gemini key in use is on the free tier, where Google may use submitted content to improve its products. Before any pilot this must move to a paid tier whose terms rule that out. The server holds one household in a JSON file behind one shared access code over plain HTTP: fine for a home network, not the public internet.
10 · Against the Meta brief

What the challenge asked, and what we did.

The brief asks forWhat we do
A clear problem and audiencePeople living with memory loss and their family carers; the repeated question and the keepsake that no longer prompts its memory.
First-person view, beyond mirroring a phoneLooking and asking are the whole interface. Nothing to find or open.
A working prototypeServer, phone app and family app run end to end, with 95 server tests and a 21-check end-to-end test on simulated glasses.
PermissionsAsked for when needed. Each missing one removes one feature.
ErrorsEvery failure has a calm spoken and written path. A look has a 12 second limit. An unsure match gives no answer.
ConnectivityWith no connection the wearer can still open memories and get recorded answers.
Intuitive and inclusiveEverything spoken is written and everything written is spoken. Two choices at most. Works without a display.
A path to a pilotOne day centre, five to ten families, four weeks, with staff helping each family set up in the first week.
11 · Not yet checked

Said plainly.

Real glasses

Nothing has run on Ray-Ban Display or audio-only glasses. Everything ran on Mock Device Kit. The Cloudinary films haven't been seen on a real lens.

Real people

Never tried with a person living with dementia. A support and comfort aid, not a treatment, with no evidence yet that it helps.

Heart rate

Only read from made-up motion replayed by Mock Device Kit, and labelled simulated wherever it shows.

Sound, browsers, screen readers

The emulator ran with audio off. The family app hasn't been checked on phones, other browsers or screen readers.
