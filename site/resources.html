Run it

You need Node 22 or newer, and Android Studio with SDK 36 for the glasses app. Keys go in server/.env, which git ignores. With no model key the server runs in rehearsal mode and recognises nothing.

Add your keys

GEMINI_API_KEY for recognition and memory lanes; CLOUDINARY_URL for the glasses films.

# server/.env
GEMINI_API_KEY=your-key
CLOUDINARY_URL=cloudinary://key:secret@cloud

Start the server and the family app

Open http://localhost:8787. The first person to arrive is walked through setup and becomes the organiser.

cd server && npm install && npm start      # http://localhost:8787
cd family && npm install && npm run build  # the server serves it at /

Install the glasses app

In the app, Connect glasses uses real glasses through the Meta AI app. Use simulated glasses uses Meta's Mock Device Kit.

adb reverse tcp:8787 tcp:8787              # the phone reaches the server over USB
cd android && ./gradlew installDebug

Or all at once

Starts the server, the emulator and the app on simulated glasses. On Windows use ./sim.sh from Git Bash.

./dev.sh

Test and measure

The demo household comes with a fortnight of use. The scorecard reports hits, misses, false matches and latency.

cd server
npm test                                   # server tests
npm run seed:recordings -- ../recordings  # the demo household
npm run scorecard -- <folder of photos>    # recognition
node ../android/e2e/run.mjs                # the whole loop, simulated glasses

Sources

Every fact on this site was checked against its source in November 2026. The full list, with caveats, is in docs/evidence.md.

  • 57 million people were living with dementia worldwide in 2021WHO dementia fact sheet · who.int/news-room/fact-sheets/detail/dementia
  • Family and friends give on average five hours of care and supervision a dayWHO dementia fact sheet, 2019 data · who.int
  • Repetitive questioning: the person often doesn't remember the answer, and may need an emotional rather than factual responseAlzheimer's Society · alzheimers.org.uk
  • Verbal repetition was a treatment target for 47% of 1,707 people with dementia; repeated questions its most common formReeve et al., International Psychogeriatrics, 2017 · doi.org/10.1017/S1041610216002180
  • Reminiscence: effects are inconsistent and often smallWoods et al., Cochrane, 2018 · cochrane.org
  • Recorded family voices (simulated presence): no conclusions could be drawnAbraha et al., Cochrane, 2020 · cochrane.org
  • What exists already: CrossSense, smart-glasses software that names objects, won the Longitude Prize on DementiaChallenge Works · challengeworks.org
Memory Lane is informed by reminiscence and carer-communication guidance. It is not clinically proven, has not been tested with people living with dementia, and is not a treatment.
